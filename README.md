# CR Rank 自動收成器

定時點擊 [CR Rank 知識領土](https://crrank.xpgs25.com/game) 上方的「收成 +金幣/建材」按鈕。單一 exe，電腦和手機都能用。

## 下載

到 [Releases](../../releases) 下載 `CRRank.exe`，直接執行即可（不用安裝 Python）。

## 電腦連點

- **選位置**：按「🎯 在螢幕上選位置」再點按鈕，或把滑鼠移到按鈕上按 **F8**；也可直接輸入 X / Y。
- **間隔**：秒 / 分 / 時，可加隨機誤差與次數上限。
- **開始 / 停止**：按鈕或 **F9**（全域熱鍵）。
- 點完預設把滑鼠移回原位。瀏覽器視窗要保持在原位、不被擋住。

## 手機

手機與電腦連同一個 Wi-Fi，用手機掃程式「手機」分頁的 QR Code：

1. **書籤 / 使用者腳本（在手機瀏覽器裡自動點）**：照頁面說明新增書籤，在遊戲頁開啟會出現可拖動的面板，可設間隔、選「自動找收成按鈕」或「點自訂位置」。有 Tampermonkey / Violentmonkey 的瀏覽器可直接安裝 `.user.js`。
2. **遙控電腦**：用手機開始 / 停止電腦端連點、改間隔。連結帶隨機密碼。

「📁 匯出手機用檔案」會產生使用者腳本、書籤碼和說明網頁。

> 手機請保持螢幕亮著、遊戲分頁在前景，否則瀏覽器會暫停計時。
> 第一次執行時 Windows 防火牆若詢問，請按「允許」，手機才連得到。

## 🛒 自動購買（v1.1）

自動收成面板裡的「🛒 自動購買」區塊，用模擬點擊幫自己買商店的東西（不呼叫遊戲 API）：

1. 展開「🛒 自動購買」，按「讀取商品」：自動打開 物品 → 商店，讀取「地形」「道具」所有商品。
2. 勾選要買的商品。
3. 選「每次補貨後買」（讀取「下次補貨」倒數）或「每 N 分鐘檢查」。
4. 按「開始自動購買」，或「立即買一次」。

每樣商品最多買到顯示的庫存數量，按鈕變灰（缺貨／已買完／錢不夠）就停，買完會關掉商店。電腦瀏覽器（書籤／使用者腳本）、Android App「內建遊戲」、iPhone Safari 書籤都能用。

## Android App（APK）

到 [Releases](../../releases) 下載 `CRRank-AutoHarvest.apk`（Android 7.0 以上），功能和電腦版相同：

- **定點連點**：透過無障礙服務在螢幕座標點擊；全螢幕「🎯 選位置」；可拖動的浮動控制鈕（▶/■ 開始停止、🎯 選位置，等同 F9 / F8）；間隔、隨機誤差、次數上限、先點一次、測試點一下。
- **手機 / 遙控**：App 內建區網伺服器，其他裝置掃 QR Code 即可遙控；書籤碼、使用者腳本、匯出檔案。
- **內建遊戲**：App 內開啟知識領土並自動出現收成面板，不需要無障礙權限。

安裝後到「開啟無障礙權限設定」開啟「CR Rank 自動收成（自動點擊）」。Android 13 以上若開關是灰色：設定 → 應用程式 → CR Rank 自動收成 → 右上角 ⋮ →「允許受限制的設定」。

建置（只需 Android SDK + JDK，不用 Gradle）：

```bash
powershell -ExecutionPolicy Bypass -File android/build.ps1
```
