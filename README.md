# CR Rank 自動收成器

定時點擊 [CR Rank 知識領土](https://crrank.xpgs25.com/game) 上方的「收成 +金幣/建材」按鈕。單一 exe，電腦和手機都能用。

## 下載

到 [Releases](../../releases) 下載 `CRRank.exe`，直接執行即可（不用安裝 Python）。

## 電腦連點

- **選位置**：按「🎯 在螢幕上選位置」再點按鈕，或把滑鼠移到按鈕上按 **F8**；也可直接輸入 X / Y。
- **間隔**：秒 / 分 / 時，可加隨機誤差與次數上限。
- **開始 / 停止**：按鈕或 **F9**（全域熱鍵）。
- 點完預設把滑鼠移回原位。瀏覽器視窗要保持在原位、不被擋住。

## 手機

手機與電腦連同一個 Wi-Fi，用手機掃程式「手機」分頁的 QR Code：

1. **書籤 / 使用者腳本（在手機瀏覽器裡自動點）**：照頁面說明新增書籤，在遊戲頁開啟會出現可拖動的面板，可設間隔、選「自動找收成按鈕」或「點自訂位置」。有 Tampermonkey / Violentmonkey 的瀏覽器可直接安裝 `.user.js`。
2. **遙控電腦**：用手機開始 / 停止電腦端連點、改間隔。連結帶隨機密碼。

「📁 匯出手機用檔案」會產生使用者腳本、書籤碼和說明網頁。

> 手機請保持螢幕亮著、遊戲分頁在前景，否則瀏覽器會暫停計時。
> 第一次執行時 Windows 防火牆若詢問，請按「允許」，手機才連得到。

## 🛒 自動購買

### 電腦版 exe／Android App：「自動購買」分頁

照順序模擬點擊螢幕座標：打開「物品」→「商店」分頁 → 商品分類 → 商品的「購買」→ 關閉商店。

1. 按「📋 建立購買範本」，先在瀏覽器把「物品 → 商店」打開到要買的商品那一頁。
2. 按「🎯 依序選全部」，照提示把每一步點在對應的按鈕上（電腦版也可以選中步驟後把滑鼠移過去按 **F8**）。
3. 要買多樣商品就「➕ 新增步驟」多加幾個「購買」；每步可設點幾次、點完等幾秒。
4. 選「每次補貨後（整點、半點）過 N 秒」或「每 N 分鐘」，按「開始自動購買」（電腦版 **F10**、Android 浮動鈕 🛒）。

開始前「物品」視窗要先關著，遊戲畫面要停在原位、不被擋住。

**存檔**：預設 3 個存檔（存檔1／2／3，可改名），步驟有任何變動都會**自動存檔**到目前的存檔。勾選「**自動輪播**」後，每次執行會做完存檔1接著做存檔2、存檔3（沒有步驟的存檔會跳過）。

**滾動**：商品在畫面下面看不到時，按「➕ 滾動步驟」，選在商品清單上的位置，設定方向（往下／往上）和格數。電腦版用滑鼠滾輪，Android 用手指滑動。

### 網頁面板（書籤／使用者腳本／內建遊戲）

自動收成面板裡的「🛒 自動購買」區塊，用模擬點擊幫自己買商店的東西（不呼叫遊戲 API）：

1. 展開「🛒 自動購買」，按「讀取商品」：自動打開 物品 → 商店，讀取「地形」「道具」所有商品。
2. 勾選要買的商品。
3. 選「每次補貨後買」（讀取「下次補貨」倒數）或「每 N 分鐘檢查」。
4. 按「開始自動購買」，或「立即買一次」。

每樣商品最多買到顯示的庫存數量，按鈕變灰（缺貨／已買完／錢不夠）就停，買完會關掉商店。電腦瀏覽器（書籤／使用者腳本）、Android App「內建遊戲」、iPhone Safari 書籤都能用。

## 🌙 背景模式（遊戲不用放在前台）

螢幕座標連點需要遊戲畫面看得到；想讓遊戲在背景跑，請用背景模式（用面板點網頁上的按鈕）：

- **用你原本的 Chrome／Edge（推薦，不用重新登入）**：電腦版「電腦連點」分頁按「🧩 用原本的 Chrome（安裝擴充功能）」，照提示在 `chrome://extensions` 打開「開發人員模式」→「載入未封裝項目」選它準備好的資料夾（只要裝一次）。之後在平常的 Chrome 打開知識領土，面板會自動出現；擴充功能每 30 秒喚醒面板一次（背景分頁也照常收成、購買、領取），並防止 Chrome 把遊戲分頁卸載。更新程式後到擴充功能頁按「重新載入」(↻) 換成新版面板。
- **電腦版專用背景視窗**（要另外登入一次）：「電腦連點」分頁按「開啟背景遊戲視窗」，會開一個專用的 Chrome／Edge 視窗（關掉背景節流，有自己的登入資料）。第一次在裡面用 Discord 登入，遊戲頁會自動出現面板；設定收成和「🛒 自動購買」按開始後，視窗可以**縮小或被蓋住**，照樣繼續點。重新整理後面板會自動放回並接續。背景模式期間電腦不會自動睡眠。
- **Android**：先在「內建遊戲」登入並在面板按開始，再按「🌙 在背景執行遊戲」（或遊戲畫面右上角「切到背景執行」）。遊戲會在看不見的視窗裡繼續跑，可以切去用別的 App；浮動鈕 🌙 點一下顯示／隱藏，長按關閉。需要無障礙權限。

面板會記住收成／自動購買是否在執行，重新載入後自動接續（按面板的 ✕ 關閉就會取消）。

也可以直接在**原本的分頁**背景跑：用書籤叫出面板後切去別的分頁即可。面板的自動購買每一步都是「等畫面變化」，不受 Chrome 背景節流影響；只有收成／檢查的間隔會被拉長到約 1 分鐘一次。建議在 Chrome 設定 → 效能 →「一律保持這些網站處於活躍狀態」加入 `crrank.xpgs25.com`。

介紹網站：https://cxu4425-beep.github.io/crrank-autoclicker/

## ⚙️ 聰明收成、自動領取、能量提醒、自動更新（v1.5）

- **聰明間隔**：面板勾「聰明間隔（快滿前才收）」，會從資源列讀每小時產量，在金幣或建材累積到 90% 前才收（例如每小時 2577 金幣 → 約 41 分鐘收一次）。電腦版／Android 的定點連點有「📊 依產量算」按鈕，輸入產量就幫你算好間隔。
- **自動領取**：面板「⚙️ 領取與提醒」勾「自動領取任務／成就／補給」，每 N 分鐘打開任務視窗，按所有可以按的「領取」（包括 Discord 每日補給），不會按「跳過」。
- **能量提醒**：能量達到設定的百分比時通知你。電腦用瀏覽器通知，Android App 用系統通知；也可以填 Discord Webhook，通知會發到你的頻道（iPhone 建議用這個）。
- **自動更新**：電腦版開啟時檢查 GitHub 有沒有新版，按「是」會自己下載並更新重開；Android 會提示下載新的 APK。

## 🌍 遠端遙控＋實時畫面（v2.0）

不用同一個 Wi-Fi：電腦版或 Android「📱 手機」分頁的「🌍 遠端遙控」QR Code，用手機掃描就能在 4G／5G 或任何網路遙控（開始／停止、點一下、改間隔、自動判斷、自動購買），還會看到實時畫面（紅圈＝會點的位置），確定設定真的有改到。

- 指令和畫面經公共 MQTT 中繼伺服器（broker.emqx.io）轉送，全程 AES-256-GCM 加密；金鑰只在連結 `#` 後面，不會傳到任何伺服器。
- 畫面只在遙控頁面開著時才傳。連結外流按「🔄 換新連結」，也可以取消「允許遠端遙控」。
- Android 11 以上才能傳畫面，第一次要把無障礙服務關掉再打開一次。

## 🤖 自動判斷每小時產量（v1.9）

不用再手動輸入產量：

- **電腦版**：「電腦連點」分頁的「🤖 自動判斷每小時產量」預設開著。程式透過 Windows 輔助功能介面讀你開著的知識領土（Chrome／Edge 分頁或安裝成 App 的視窗，不用登入、不用擴充功能），看「+產量/時」和「收成 +金幣/建材」，每次收完算出金幣或建材快滿（90%）前的時間再收。
- **Android**：定點連點點完收成後，透過無障礙服務讀遊戲畫面算下一次。更新後請到無障礙設定把服務關掉再打開一次（讓它可以讀取畫面文字）。
- 讀不到遊戲時自動改用設定的固定間隔。

## Android App（APK）

到 [Releases](../../releases) 下載 `CRRank-AutoHarvest.apk`（Android 7.0 以上），功能和電腦版相同：

- **定點連點**：透過無障礙服務在螢幕座標點擊；全螢幕「🎯 選位置」；可拖動的浮動控制鈕（▶/■ 開始停止、🎯 選位置，等同 F9 / F8）；間隔、隨機誤差、次數上限、先點一次、測試點一下。
- **手機 / 遙控**：App 內建區網伺服器，其他裝置掃 QR Code 即可遙控；書籤碼、使用者腳本、匯出檔案。
- **內建遊戲**：App 內開啟知識領土並自動出現收成面板，不需要無障礙權限。

安裝後到「開啟無障礙權限設定」開啟「CR Rank 自動收成（自動點擊）」。Android 13 以上若開關是灰色：設定 → 應用程式 → CR Rank 自動收成 → 右上角 ⋮ →「允許受限制的設定」。

建置（只需 Android SDK + JDK，不用 Gradle）：

```bash
powershell -ExecutionPolicy Bypass -File android/build.ps1
```
