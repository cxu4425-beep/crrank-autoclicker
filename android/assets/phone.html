方法一：在手機瀏覽器裡自動點（推薦）

先按這個按鈕複製書籤碼，再照你的手機選下面的教學：

🍎 iPhone / iPad（Safari）教學
1
按上面的 📋 複製書籤碼。如果跳出「請手動複製」，就長按文字框 → 全選 → 拷貝。
2
在 Safari 開著這一頁，點下方的 分享 按鈕，選 加入書籤 → 右上角 儲存。
Safari 下方工具列
加入書籤📖
3
點 書籤 按鈕（打開的書）→ 右下角 編輯 → 點剛剛新增的那個書籤。
自動收成 · 手機›
編輯
4
把名稱改成 收成；把網址那一格全部刪掉，長按 → 貼上剛剛複製的書籤碼（開頭是 javascript:）→ 完成。

5
打開 知識領土遊戲頁 並登入 → 點 書籤 按鈕 → 點 收成，畫面左上就會出現「自動收成」面板。設定間隔、選「自動找收成按鈕」或「點自訂位置」，按 開始。
6
重要：iPhone 鎖定畫面或切到別的 App 時，Safari 會暫停計時。請到 設定 → 螢幕顯示與亮度 → 自動鎖定 → 永不，並讓遊戲分頁停在畫面上（可以把亮度調低省電）。

想要每次進遊戲自動出現面板？到 App Store 安裝免費的「Userscripts」→ 到 設定 → App → Safari → 延伸功能（舊版 iOS：設定 → Safari → 延伸功能）開啟 Userscripts，並允許所有網站 → 用 Safari 開 使用者腳本 → 點網址列旁的 ᴀA / 拼圖按鈕 → Userscripts → 安裝。

🤖 Android（Chrome）教學
1
按上面的 📋 複製書籤碼。
2
點右上角 ⋮ → ☆ 把這頁加入書籤 → 點下方出現的 編輯，名稱改成 收成，網址整個換成剛複製的內容。
3
打開 知識領土遊戲頁 並登入 → 在網址列輸入「收成」，點選下面出現的書籤那一項，面板就會出現。

也可以安裝 Android App（GitHub Release 的 CRRank-AutoHarvest.apk），或在 Firefox／Kiwi／Edge 裝 Tampermonkey 後安裝 使用者腳本。手機請保持螢幕亮著、遊戲分頁在前景。
