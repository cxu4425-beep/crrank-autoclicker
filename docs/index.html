功能

兩種點法都有：照螢幕位置點（像真的滑鼠），或直接在網頁裡找到按鈕點。

🌾

自動判斷產量收成

自己讀遊戲畫面上的每小時產量和還沒收的數量，在金幣／建材快滿（90%）前收，產量變了也跟著變，不用手動輸入。也能自訂固定間隔。

🎁

自動領取

定時打開任務視窗，把任務、成就、Discord 每日補給能領的「領取」都按掉，不會按「跳過」。

🔔

能量快滿提醒

能量到你設定的百分比就通知你回來答題：瀏覽器通知、Android 系統通知，或發到你的 Discord 頻道。

🎯

自訂點擊位置

在螢幕上點一下就記住位置，電腦版也能把滑鼠移過去按 F8 記錄。

🛒

自動購買

勾選要買的商品，或照順序點「物品 → 商店 → 分類 → 購買」。每樣最多買到庫存數量，缺貨就停。

⏰

補貨時自動買

商店每 30 分鐘（整點、半點）補貨，可設定補貨後幾秒去買，或每 N 分鐘檢查一次。

💾

3 個存檔＋輪播

購買步驟自動存檔，可以存 3 組；開「自動輪播」就會做完存檔1接著做存檔2、存檔3。

🖱️

支援滾動

商品在畫面下面看不到時，加一個滾動步驟先捲過去再買（電腦用滾輪、手機用滑動）。

🌙

背景與息屏也收成

電腦裝一次擴充功能，在原本的 Chrome／Edge（不用重新登入）背景照常收成；Android 息屏時自動改用背景遊戲繼續收成。

📱

遠端遙控＋實時畫面

手機掃 QR Code，4G／5G 也能遙控，不用同一個 Wi-Fi；還看得到實時畫面，確定真的有改到。全程加密。

🔄

自動更新

電腦版開啟時檢查新版，按一下就自己下載、替換、重開；Android 會提示下載新的 APK。

🤖

Android App

功能和電腦版一樣：浮動控制鈕、全螢幕選位置，還有內建遊戲模式（不用開無障礙權限）。

下載與使用

選你的裝置，照著做就好。

💻 Windows

Windows 10／11
  1. 下載 CRRank.exe，直接打開（不用安裝）。
  2. 打開知識領土，在「電腦連點」分頁按「🎯 在螢幕上選位置」，點一下「收成」按鈕。
  3. 設定間隔，按 F9 開始。
  4. 要自動買東西：到「自動購買」分頁按「📋 建立購買範本」，照提示選位置，按 F10。
  5. 不想讓遊戲一直在前面：按「🧩 用原本的 Chrome（安裝擴充功能）」，照提示在擴充功能頁「載入未封裝項目」（只要一次），之後在平常的 Chrome 打開遊戲就會有面板，放背景也會繼續跑。

🤖 Android

Android 7.0 以上
  1. 下載安裝 CRRank-AutoHarvest.apk（要允許安裝未知來源的 App）。
  2. 按「開啟無障礙權限設定」，打開「CR Rank 自動收成」。Android 13 以上開關是灰色的話：App 資訊 → 右上角 ⋮ →「允許受限制的設定」。
  3. 用浮動鈕的 🎯 選位置，▶ 開始。
  4. 不想開權限？用「內建遊戲」分頁，面板會自動出現。
  5. 想切去用別的 App：在內建遊戲按開始後，選「🌙 切到背景執行」。

🍎 iPhone／iPad

Safari 書籤
  1. iPhone 和電腦（或 Android）連同一個 Wi-Fi，用相機掃程式「手機」分頁的 QR Code。
  2. 照頁面裡的 iPhone 教學：複製書籤碼 → 加入書籤 → 把書籤網址換成書籤碼。

常見問題

遊戲一定要放在前面嗎？

不用。照螢幕位置點的模式（電腦版連點、自動購買分頁）才需要看得到遊戲畫面。想在背景跑有兩種方式：

  • 擴充功能（推薦）：電腦版按「🧩 用原本的 Chrome」，在擴充功能頁打開「開發人員模式」→「載入未封裝項目」選它準備好的資料夾，只要裝一次。用你原本已登入的 Chrome／Edge，不用重新登入；每 30 秒喚醒面板，背景分頁照常收成、購買、領取，Chrome 也不會把遊戲分頁卸載。
  • 專用背景視窗：電腦版「開啟專用背景視窗」，完全不受背景節流，但要在裡面另外登入一次；期間電腦不會自動睡眠。
  • Android：內建遊戲按開始後，選「🌙 切到背景執行」。
擴充功能更新後要做什麼？

更新電腦版程式後，它會自動把擴充功能的檔案換成新版；到 chrome://extensions（Edge：edge://extensions）按這個擴充功能的「重新載入」(↻)，再重新整理遊戲頁就好。

Android 關螢幕也會收成嗎？

會（v1.8 起）。螢幕關掉時系統不讓 App 點螢幕，所以「定點連點」息屏期間會自動改用背景遊戲，由網頁面板直接按「收成」；解鎖後換回定點連點並馬上補點過期的。要先在「內建遊戲」分頁登入一次，並建議按「🔋 允許在背景不受省電限制」，不然息屏久了手機省電可能讓它斷線。

手機上要注意什麼？

手機的瀏覽器在鎖定畫面或切到別的 App 時會暫停，請讓螢幕保持亮著、遊戲分頁留在前面（可以把亮度調低省電）。

能量提醒要怎麼發到 Discord？

在你的 Discord 伺服器：頻道設定 → 整合 → Webhook → 新 Webhook → 複製網址，貼到面板「⚙️ 領取與提醒」的 Discord Webhook 欄位，按「測試通知」確認。iPhone 的 Safari 不支援網頁通知，建議用這個方式。Webhook 網址只存在你自己的瀏覽器裡，不要分享給別人。

遊戲用「在應用程式中開啟」的視窗，也能自動判斷產量嗎？（v2.4）

可以。Chrome 平常會把網頁內容對輔助工具關起來，所以 v2.4 起有三種讀法：① 有裝擴充功能（「🧩 用原本的 Chrome」）最準，分頁和應用程式視窗都會每 30 秒把產量交給程式（只送到你自己電腦的 127.0.0.1）；② Chrome 有打開輔助功能時直接讀網頁；③ 都不行時（v2.5 起）用 Windows 內建的畫面辨識讀每次收成跳出的「領取產出 +金幣、+建材」，用「這次收了多少 ÷ 距離上次收成多久」算出產量，第一輪會先 5 分鐘收一次，大約 10 分鐘就有準確結果（遊戲畫面要露出來）。更新程式後記得到 chrome://extensions 按擴充功能的「重新載入」。

每次遙控都要掃 QR Code 嗎？（v2.1）

不用。掃一次就會記在手機上，之後直接打開遙控頁面（建議「加到主畫面」）就會自動連上；可以記好幾台、在最上面切換，也能改名、刪除。Android App 在「📱 手機/遙控」分頁按「🖥 打開遙控電腦」就好，也可以貼上電腦版「🔗 複製連結」的連結加入。

遠端遙控安全嗎？畫面會被別人看到嗎？（v2.0）

指令和畫面經公共 MQTT 中繼伺服器（broker.emqx.io）轉送，但全部用 AES-256-GCM 加密，金鑰只存在 QR Code 連結的 # 後面，瀏覽器不會把它傳到任何伺服器，中繼伺服器看不到內容。畫面只在遙控頁面開著時才傳。連結等於遙控器，不要分享；外流的話在程式裡按「🔄 換新連結」，舊的就失效。不想用可以取消勾選「允許遠端遙控」。

自動判斷每小時產量要怎麼用？（v1.9）

電腦版預設就開著：在 Chrome／Edge（或安裝成 App 的視窗）打開知識領土就好，不用登入、不用裝東西。程式會透過 Windows 的輔助功能介面讀畫面上的「+產量/時」和「收成 +x/y」，每次收完自動算下一次。Android 要把無障礙服務關掉再打開一次，讓它可以讀取畫面文字。讀不到遊戲時會改用你設定的固定間隔。

聰明間隔是怎麼算的？

遊戲上方的金幣、建材會寫「每小時產出」，沒收成的產出最多累積金幣 2000、建材 1500，滿了就停產。聰明間隔會算哪一種先到 90%，在那之前收一次（例如每小時 2577 金幣 → 約 41 分鐘）。

第一次用自動購買要怎麼確認設定對不對？

先勾一樣便宜的商品（例如能量藥水），按「立即買一次（測試）」看看有沒有點對位置、買到東西，再按開始。

Windows 說這個檔案不常見、跳出警告？

因為程式沒有買數位簽章，Windows SmartScreen 可能會提醒。按「其他資訊 → 仍要執行」即可；不放心的話可以看 GitHub 上的原始碼自己打包。第一次開啟時防火牆詢問要按「允許」，手機遙控才連得到。

會收集我的資料嗎？

不會。程式只在你的電腦／手機上執行，手機遙控只在你家的區網內連線，而且連結帶有隨機密碼。

⚠️ 這是玩家自製的非官方工具，和 CR Rank 官方無關。自動點擊可能違反遊戲規則，請自行斟酌，使用風險自負。
